# הדמיית מטבח 3D

מערכת הדמיה בתלת־ממד לנגרים — תכנון מטבח מול הלקוח לפני סגירת עסקה.

## הרצה מקומית

```bash
cd standalone/kitchen-visualizer
npm install
npm run dev
```

## מה יש כרגע

- חדר עם מידות מותאמות (ס״מ)
- קטלוג ארונות: תחתונים, עליונים, כיור, גבוה, אי
- בחירת חומרי גוף ומשטח
- הצבה בקליק על הרצפה, סיבוב, מחיקה
- שמירת תמונה PNG לשליחה ללקוח
